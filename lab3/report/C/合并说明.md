# 合并说明

本包基于用户提供的 `OS2026_w-y-y-lab3.zip` 中 `lab3/code` 快照，不包含队友其他源文件，也不会自动推送仓库。

1. 在队友仓库的 `lab3` 分支，进入含 `kern/` 的 `lab3/code` 目录。先确认并保存现有改动。
2. 将本包的 `C组异常处理.patch` 路径替换到下面命令：

   ```sh
   git apply --check /path/to/C组异常处理.patch
   git apply /path/to/C组异常处理.patch
   ```

   如果检查失败，说明版本或同一位置已有改动；不要强制覆盖。打开 `exception_handler.c.txt`，人工将该函数合并到 `kern/trap/trap.c` 的 C 组预留位置，避免重复定义，并保留队友的 `interrupt_handler()`。
3. 将 `test_exception.py` 复制为 `lab3/code/tests/test_exception.py`，在 `lab3/code` 下运行 `python3 tests/test_exception.py` 和 `make -j2`；按报告进行 QEMU 测试。
4. 阅读 `C组实验报告.md` 并填写姓名、学号、班级；`测试日志/` 为本次测试的原始输出。

补丁仅修改 `kern/trap/trap.c` 的 C 组占位区，不改 A、B 实现；函数文本供冲突时人工合并。日志不能替代队友自己环境的重测。
