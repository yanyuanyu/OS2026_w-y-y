# 本轮测试截图说明

六张截图均来自 2026-10-28 新执行的测试进程。截图前先运行测试，再用原生窗口截图工具采集 Live WSL Test 窗口，并逐张检查。

该窗口是本地实时测试控制台：live_runner.py 启动新的 WSL 子进程，逐行显示 stdout；不是读取旧日志的展示器。图片按截图工具返回的 JPEG 原字节保存，没有重绘、拼接、修改成功输出或分数，也没有裁剪、缩放。QEMU 从 DTB Init 起显示实时串口以便在一张图内阅读，完整 OpenSBI 横幅与串口输出仍保留在日志中。

| 02-qemu-default.jpg | 启动默认配置镜像 | 十行 100 ticks，QEMU 正常退出 |
