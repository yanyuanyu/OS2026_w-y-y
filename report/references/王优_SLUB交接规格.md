# 王优交接的 SLUB 复现规格

来源：王优交付包《报告/提示词与规格记录.md》第 3.5、3.6 节。

### 3.5 SLUB Challenge 实现

> 在页分配器之上实现教学版单 CPU SLUB，接口为 `slub_init/slub_alloc/slub_free/slub_check`。小对象采用 16、32、64、128、256、512、1024、2048 字节大小类，每个 slab 占一页，页首保存 magic、类别、占用数、空闲链和分配位图；返回地址至少 16 字节对齐，空 slab 归还 PMM。大于 2048 字节的对象走连续页路径并在首部记录页数。零长度、大小计算溢出和页数不足返回 NULL。明确它不是 Linux 完整 SLUB，不实现 per-CPU、NUMA 和并发同步。

### 3.6 SLUB 测试

> 写内核态 SLUB 自检：覆盖大小 1 到 9000 的各大小类边界，检查 16 字节对齐、对象区间不重叠和全长度哨兵值；检查 0、SIZE_MAX、超过空闲页数请求返回 NULL 且计数不变；分配 140 个 64 字节对象跨越多个 slab，释放偶数槽并重新分配，确认复用空位而不再取页且未释放对象数据不变；最后逆序或全部释放，`nr_free_pages()` 必须恢复初值。分别在 Best-Fit、First-Fit、Buddy 后端运行。
